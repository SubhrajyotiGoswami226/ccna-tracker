## 📖 Overview

CCNA Master Tracker is a modern web application designed to help aspiring network engineers prepare for the **Cisco Certified Network Associate (CCNA 200-301)** certification.

Instead of using spreadsheets or notebooks, this application provides a beautiful dashboard where users can monitor study progress, complete weekly topics, track labs, revise commands, and stay consistent throughout their CCNA journey.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/yourusername/ccna-master-tracker.git
```

## Navigate

```bash
cd ccna-master-tracker
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Visit

```
http://localhost:5173
```
